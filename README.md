# 🧠 Mental Health Prediction using Machine Learning

This project aims to leverage machine learning algorithms to predict an individual's mental health status based on behavioral, social, and health-related features. The primary goal is to create an intelligent system that helps identify mental health concerns early, allowing for timely intervention and support.

## 💡 Problem Statement

With rising mental health issues globally, early detection becomes crucial. However, stigma and lack of awareness often delay intervention. Our model attempts to fill this gap by predicting potential mental health risks using survey-based features, thus aiding both individuals and institutions in taking proactive steps.

---

## 🛠️ Technologies Used

- Python  
- Scikit-learn  
- Pandas & NumPy  
- Matplotlib & Seaborn

---

## 🧪 Features & Models

- **Data Preprocessing**: Null handling, encoding, feature selection  
- **Some ML Models Used**:
  - Logistic Regression  
  - Random Forest  
  - Support Vector Machine (SVM)  
  - K-Nearest Neighbors (KNN)
- **Model Adopted**: AdaBoost Classifier
- **Evaluation Metrics**: Accuracy, Precision, Recall, F1-Score, Confusion Matrix  

---

## 📊 Dataset

Our dataset is survey-based, collected from open mental health-related sources, focusing on work environment, family history, and accessibility of mental health resources.
